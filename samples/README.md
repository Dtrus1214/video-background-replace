# Video background replacement sample

Open `demo/replaced.mp4` to see the person over a moving background, or
`demo/preview.jpg` for a side-by-side still. `demo/replaced.avi` is the direct
application output; the MP4 is a smaller viewing copy. Clips have no audio.

`demo/replaced-pytorch.avi` is the equivalent output from the original PyTorch
checkpoint backend (48 frames). To use that backend with the example command,
replace `--model models/matanyone2-onnx` with `--model models/matanyone2.pth` after
installing the [PyTorch offline dependencies](../offline/python310-pytorch/README.md).

`demo/replaced-auto.mp4` (or the direct `demo/replaced-auto.avi` output) demonstrates
fully automatic initialization: no manual
mask was supplied. `demo/automatic-mask.png` is the mask generated by the local
person-segmentation model. Run it yourself with:

```powershell
python python/replace_background.py --model models/matanyone2.pth --input samples/demo/person.mp4 --background samples/demo/background.mp4 --background-start 0.5 --background-end 1.5 --output samples/demo/my-auto-result.avi
```

`demo/automatic-preview.jpg` shows the original and automatic-mask result side
by side. The generated mask is provided for inspection, not as an input you
need to prepare yourself.

Files for running the example offline:

- `demo/person.mp4`: shortened/resized person video (48 frames).
- `demo/mask.png`: first-frame person mask, white foreground / black background.
- `demo/background.mp4`: three seconds of moving shapes and a visible time label.
- `demo/replaced.mp4`: approximately two seconds of replaced-background output.

From the project root, with the Python 3.10 offline packages installed:

```powershell
python python/replace_background.py --input samples/demo/person.mp4 --mask samples/demo/mask.png --background samples/demo/background.mp4 --background-start 0.5 --background-end 1.5 --model models/matanyone2-onnx --output samples/demo/my-result.avi
```

Only background seconds **0.5 through 1.5** are selected. That one-second section
loops until the person video finishes. These times select the background content;
replacement remains active for the entire person video. The end is exclusive.

To recreate all sample artifacts in a new directory:

```powershell
python tools/create_sample_video.py --source samples/original.mp4 --mask samples/person-mask.png --output samples/recreated
```

The original footage and mask are from the official MatAnyone 2 demonstration:
[video](https://github.com/pq-yang/MatAnyone2/blob/0079197acd6d16a741f71558809c06c586c579e0/inputs/video/test-sample2.mp4),
[mask](https://github.com/pq-yang/MatAnyone2/blob/0079197acd6d16a741f71558809c06c586c579e0/inputs/mask/test-sample2.png).
They are retained here for a local demo; see the upstream project's terms and
[license notice](../licenses/MatAnyone2-LICENSE.txt). The moving-shapes background
is generated by this project's sample script. The mask is padded for the original
sample's encoder padding before resizing. This small 512x290 example demonstrates
timing and compositing, not maximum-resolution quality.
